# Engineering Dev Path

Учебный репозиторий: изучение **Python** и **C#** применительно к работе инженера-конструктора.

Бэкграунд: C++ (3D-viewer для `.obj`, тетрис, змейка, ручная работа с памятью), плагины для Autodesk Inventor.
Цель: дополнительная квалификация, автоматизация инженерных задач, расчёты, расширения CAD.

## Принцип

Код пишу я сам. Claude выступает наставником: ставит задачи, даёт подсказки, делает ревью.
Подробнее в [docs/workflow.md](docs/workflow.md).

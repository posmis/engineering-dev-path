# Программа обучения

Каждый проект — законченный инструмент, полезный в работе конструктора.
Темы языка изучаются по мере необходимости в проекте, а не отдельно.

Акцент — на отличиях от C++: управление памятью (GC), идиомы языка, экосистема, инструменты.

---

## 01 · Python · Анализатор `.obj`

Знакомый формат, поэтому всё внимание уходит на язык.

- Синтаксис, типы, коллекции (`list`, `dict`, `tuple`), распаковка, генераторы списков
- Функции, аннотации типов, `dataclass`
- Файлы, `argparse`, обработка ошибок
- numpy: векторизация вместо циклов, сравнение скорости
- pytest, структура пакета, `pyproject.toml`, виртуальные окружения

## 02 · C# · Add-in для Inventor: пакетный экспорт

Экспорт чертежей папки/сборки в PDF/DXF, выгрузка BOM в Excel.

- .NET, проект Class Library, NuGet
- Классы, интерфейсы, свойства, `using`/`IDisposable`, исключения
- Коллекции и LINQ
- Inventor API: `ApplicationAddInServer`, кнопки на ленте, `TranslatorAddIn`, BOM
- Отладка add-in'а в Visual Studio

## 03 · Python · Расчётный модуль

Расчёт типового узла (вал / болтовое соединение / сварной шов) с графиками и отчётом.

- Jupyter как замена Excel/Mathcad
- numpy, scipy, matplotlib
- Единицы измерения (`pint`)
- Генерация отчёта (Markdown / HTML / PDF)

## 04 · C# · WPF: каталог стандартных изделий

Подбор подшипников / крепежа из базы с фильтрами.

- WPF, XAML, привязки данных, паттерн MVVM
- SQLite, Entity Framework Core
- `async`/`await`

## 05 · Python · Параметрическая модель кодом

Генератор типовой детали по параметрам с экспортом в STEP.

- build123d или CadQuery
- Проектирование архитектуры: модули, классы, конфигурация
- Валидация входных параметров

## 06 · C# + Python · Интеграция

Add-in берёт параметры из модели Inventor, отправляет в расчётный сервис, показывает результат.

- REST API на FastAPI
- `HttpClient`, JSON в C#
- Связка двух языков в одном решении
